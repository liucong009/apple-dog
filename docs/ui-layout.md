# UI 布局草案（线框级）

尚无视觉稿；以下为 **信息架构 + 槽位**，与 `internal/island` 字段一一对应。CLI 用 ASCII 预览，见 `internal/render`。

## 1. Compact（紧凑 / 药丸）

系统药丸近似 `126×37 pt` 量级（随设备略有差异）；两侧为 leading / trailing。

```text
┌──────────────────────────────────────────┐
│  [L: icon+短文本]    (pill)    [R: 数值] │
└──────────────────────────────────────────┘
     Leading                      Trailing
```

**槽位规则（草案）**

- Leading：品牌色图标 + ≤4 字中文或短英文缩写。
- Trailing：数字、倒计时、状态 glyph；避免长句。
- 无第三行；动画由 Swift 侧实现，Go 仅描述 `AnimationHint` 占位。

### 示例：天气插件

```text
┌──────────────────────────────────────────┐
│  ☀ 24°                      海淀 · 晴   │
└──────────────────────────────────────────┘
```

### 示例：计时插件

```text
┌──────────────────────────────────────────┐
│  ⏱ 番茄                    12:34       │
└──────────────────────────────────────────┘
```

## 2. Minimal（多活动并存）

当系统同时存在多个 Live Activity 时，岛可能缩为 **minimal** 指示（如单图标）。

```text
        ┌────┐
        │ 🔔 │  ← 单 glyph，细节在展开或 App 内
        └────┘
```

本仓库：`MinimalLayout.Glyph` 字符串占位；宿主合并策略见 `docs/plugin-integration.md`。

## 3. Expanded（展开）

展开态分 **上 / 中 / 下** 三区（映射 `ExpandedLayout.Regions`）。

```text
┌─────────────────────────────────────────────┐
│  Title · 副标题                    [插件徽标] │  ← Top
├─────────────────────────────────────────────┤
│                                             │
│            主内容区（图表/列表/大号时间）        │  ← Center
│                                             │
├─────────────────────────────────────────────┤
│   [次要操作]              [主操作 · 强调]    │  ← Bottom
└─────────────────────────────────────────────┘
```

**交互**

- Bottom 最多 2 个 `Action`（草案）；实际可点击性在 SwiftUI 实现。
- Center 允许滚动内容时，需在 Swift 侧用 `DynamicIslandExpandedRegion` 约束高度。

### 示例：天气展开

```text
┌─────────────────────────────────────────────┐
│  北京 · 晴                          天气    │
├─────────────────────────────────────────────┤
│  24°  体感的 26°                            │
│  18:00 22°  ·  21:00 20°  ·  00:00 18°     │
├─────────────────────────────────────────────┤
│  刷新                         打开详情 ›    │
└─────────────────────────────────────────────┘
```

## 4. Companion App 屏（宿主 App，非岛上）

```text
┌──────────────── App: 灵动岛拓维 ────────────────┐
│  [Tab: 岛上预览]  [Tab: 插件]  [Tab: 设置]       │
├─────────────────────────────────────────────────┤
│  「岛上预览」                                    │
│   ┌ compact / expanded 切换 ─────────────┐    │
│   │  （内嵌 SwiftUI 预览或静态线框）        │    │
│   └──────────────────────────────────────┘    │
│  当前主插件: 天气 ▼                            │
├─────────────────────────────────────────────────┤
│  「插件」                                        │
│   □ 天气    已启用   优先级 10                   │
│   □ 计时    已启用   优先级 20                   │
│   + 安装更多插件（占位）                         │
└─────────────────────────────────────────────────┘
```

Go CLI 子命令 `companion` 输出上述结构的 **纯文本线框**，便于 PR 评论。

## 5. 与代码的对应

| 文档区域 | Go 类型 |
|----------|---------|
| Leading / Trailing | `island.Slot` |
| Expanded 三区 | `island.Region` + `RegionKind` |
| 伴生 Tab | `island.CompanionLayout` |
| 按钮 | `island.Action` |
